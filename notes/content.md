## 第一幕 · LLM 背景（最小必要理论）

### ③ LLM 是什么 · 一个文字接龙机器  `~2.5min`

- **目标**：30 秒建立"逐 token 生成"的正确直觉
- **画面** `[F]`：① 一句话定义："大语言模型只做一件事：预测下一个字"；② 演示条：输入"海绵宝宝去蟹堡王上"，逐字接出"班，路上遇到了派大星……"；③ 关键句："所谓'人设'，本质上只是喂给它的文字"
- **动效**：`[LIVE]` 接龙逐字动画（SplitText；模拟=罐头节奏，LIVE=真调 DeepSeek）
- **讲者备注**：
  - "文字接龙"类比贯穿全场，反复回扣
  - 没有神秘的"灵魂"，只有概率——每个字都是一个一个猜出来的
  - 它不知道"自己是谁"，除非你告诉它
  - **串场**："接龙机器有个天生的毛病——记性差。"

### ④ 它没有记忆 · 上下文窗口  `~3min`

- **目标**：理解"每轮都重发全部历史"——这是理解 ST 一切功能的地基
- **画面**：交互模拟器——上方聊天记录逐条累积，下方固定宽度的"窗口"槽位；拖动滑块（或自动播放）看消息变多 → 塞满 → 最早的消息被挤出（淡出+移出）
- **动效**：挤出时配一行小字："它'忘了'——因为那些字已经不在这次请求里了"
- **讲者备注**：
  - 失忆不是故障，是物理限制：每次请求都要把历史全部重发一遍
  - 窗口 = 模型一次能"看见"的字数上限
  - 记住这页：后面世界书、总结、向量检索全是在这件事上打补丁
  - **串场**："大脑有了毛病，就需要一个懂它的管家——酒馆登场。"

## 第二幕 · ST 是什么

### ⑤ 身世与定位 · 为"折腾党"而生  `~2.5min`

- **目标**：给出 ST 的身份卡
- **画面** `[F]`：① 定位（官方原话）："LLM Frontend for Power Users"；② 时间线：TavernAI 分叉（2023）→ 社区接管 → **v1.19.0（2026.09）**，AGPL-3.0，仍在活跃更新；③ 三标签：开源免费 / 高度可定制 / 社区生态庞大；④ 中文圈昵称："酒馆"
- **动效**：时间线横向生长
- **讲者备注**：
  - "Silly"（傻乎乎）是自嘲——给爱折腾的人准备的瑞士军刀
  - B 站上叫它"酒馆"，今晚我们也这么叫
  - 十几年前的开源项目活了三年还在周更，社区就是它的命
  - **串场**："它凭什么能接这么多大脑？因为架构上就把界面和大脑拆开了。"

### ⑥ 架构 · 前端与后端分离  `~3min`

- **目标**：建立"界面 ≠ 智能"的核心图式（全场最重要的一页）
- **画面**：左右架构图。左：你手机/电脑上的酒馆界面（前端）；右：任意一个"大脑"（DeepSeek / GLM / 本地模型 / 免费 Horde）；中间一条线：API 请求（你的全部上下文）→ / ← 回复流
- **动效**：请求包从左到右飞行、回复流逐点返回；`[LIVE]` 现场真发一次（LIVE 时此图与真实请求同步点亮——前端/后端分离的活证据）
- **讲者备注**：
  - ChatGPT 是捆绑套餐：界面和大脑焊死
  - 酒馆把界面拆出来单卖——大脑随你换，改一个接口地址就行
  - 今天的 LIVE 演示和最后的体验站，用的都是这条原理
  - **串场**："拆开之后，'大脑货架'上有什么？"

### ⑦ 万能插头 · 能接的模型谱系  `~2.5min`

- **画面** `[F]`：三行清单，每行一个色块——
  - 云端 API：DeepSeek / GLM / Qwen / Claude / Gemini / OpenRouter…
  - 本地模型：KoboldCpp / llama.cpp / Ollama，笔记本就能跑小模型
  - 完全免费：AI Horde 众包算力、Pollinations——均开箱即用
- **要点**：换模型 = 改一个接口地址，界面、角色卡、聊天记录全部不动
- **讲者备注**：
  - 对同学最实际：免费档就能玩全部功能
  - 想要质量：DeepSeek Flash 档一次对话不到一分钱
  - 本地模型 = 断网也能玩，宿舍里就行
  - **串场**："大脑在别人服务器上，那我的数据呢？"

### ⑧ 你的数据在你手里  `~2min`

- **画面**：对比图——左"网页服务：聊天记录在别人服务器"；右"酒馆：跑在你自己机器上，聊天记录/角色卡/设定全是本地文件"
- **要点**：跨平台（Win/Mac/Linux，手机浏览器直接访问）；文件即资产（可备份、可分享、可搬家）
- **讲者备注**：
  - 数据不绑架人：想搬走随时打包带走
  - 这也是它适合当社团基础设施的原因
  - **串场**："好处说完了，该说大实话了。"

### ⑨ 诚实的定位 · 它适合谁  `~2min`

- **画面**：左右两栏对照。✅ 适合：想掌控细节的人 / 想理解 LLM 原理的人 / 创作者·跑团党·陪练党；❌ 不适合：只想开箱即用的人（一句带过 RisuAI 等更轻的替代）
- **讲者备注**：
  - 诚实曲线是信任曲线：它有安装门槛、有学习曲线
  - "门槛本身就是今晚要拆掉的东西。"
  - 只想轻量聊天：RisuAI 等更轻的选择也值得看
  - **串场**："那它到底能玩出什么花？进入第三幕。"

## 第三幕 · 能做什么

### ⑩ 角色卡 · 一张 PNG 的魔法  `[HOTSPOT→卡结构深挖]`  `~3min`

- **目标**：引出第一个核心概念：结构化提示词
- **画面**：左边一张角色卡 PNG（教学演示卡，imagegen #4），右边"拆开"动画分层：名字/描述/性格/场景/示例对话/首条消息——每层标注"其实都是提示词字段"
- **动效**：`[F]` 逐层展开；LIVE 模式下右侧字段就是真实 V2 卡的 JSON 摘要
- **讲者备注**：
  - 角色扮演的秘密 = 一张填好模板的表
  - PNG 里藏着结构化 JSON——图片是皮，数据是魂
  - 社区百万张卡流通格式统一（V2/V3 规范互通），别人的卡直接导入就能玩
  - **串场**："一个角色是独角戏，一群角色呢？"

### ⑪ 群聊 · 让角色同台  `~2min`

- **画面**：群聊界面示意：多个角色头像，AI 扮演多角色互相接话，你@谁谁说话
- **要点**：多角色编排 / 说话顺序可设 / 自动模式
- **讲者备注**：
  - 一个模型，一次演一台戏
  - 原理没变——还是接龙，只是提示词里写了"你现在扮演房间的所有人"
  - **串场**："设定太多记不住？下一页是酒馆最聪明的设计。"

### ⑫ 世界书 · 会自己出现的设定  `[HOTSPOT→触发机制深挖]`  `~3min`

- **目标**：埋 RAG 的种子，但先不讲名词
- **画面**：设定库列表（蟹堡王、比奇堡、章鱼哥…），下面聊天进行中——用户打出"蟹堡王"，那条设定高亮并"飞入"上方的请求包
- **动效**：关键词命中 → 条目注入动画；未命中条目保持灰色沉睡
- **讲者备注**：
  - 设定太多塞不下怎么办？酒馆的办法：平时睡觉，提到才加载
  - "记住这个动作，第四幕我们给它一个学名。"
  - **串场**："光有设定还不够，酒馆的插件货架同样夸张。"

### ⑬ 扩展生态 · 给酒馆装插件  `~2.5min`

- **画面** `[F]`：插件货架逐个亮起——TTS 语音 / AI 绘图 / 自动翻译 / 聊天总结记忆 / 正则（输出渲染成状态栏、属性面板）/ 用户脚本
- **讲者备注**：
  - 重点不是功能多：所有插件都在同一件事上加料——改写"发出去的文字"，或美化"收回来的文字"
  - 又回到那句话：一切皆是提示词的加工
  - **串场**："插件还能把界面整个换掉。"

### ⑭ 界面 · 从极客到手机 App  `~2min`

- **画面**：三张真实截图横排（本机 ST 实拍）：桌面深色主题 / 手机竖屏（像聊天 App）/ 自定义状态栏皮肤
- **要点**：主题全可换；手机浏览器直接用；正则+CSS 能把消息渲染成游戏 UI
- **讲者备注**：

  - 界面是前端 → 所以皮肤随便换，大脑不受影响（回扣第⑥页）
