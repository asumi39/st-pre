## 第一幕 · LLM 背景（最小必要理论）

### ③ LLM 是什么 · 一个文字接龙机器  `~2.5min`

- **目标**：30 秒立住「逐 token 生成」的直觉
- **画面** `[F]`：① 一句话定义：「大语言模型平生只干一件事：猜下一个字」；② 演示条：输入「海绵宝宝去蟹堡王上」，逐字接出「班，路上遇到了派大星……」；③ 关键句：「所谓『人设』，不过是你提前喂给它的字」
- **动效**：`[LIVE]` 接龙逐字动画（SplitText；模拟=罐头节奏，LIVE=真调 DeepSeek 当场现猜）
- **讲者备注**：
  - 咬死「文字接龙」这个比方，全场反复回扣
  - 挑明底牌：哪有什么神秘的「灵魂」，只有概率——字字都是当场一个个猜出来的
  - 它压根不知道「自己是谁」，除非你先把字喂给它
  - **串场**：「这台接龙机器有个胎里带的毛病——记性差。」

### ④ 它没有记忆 · 上下文窗口  `~3min`

- **目标**：吃透「每聊一轮都得重发全部旧账」——这是看懂 ST 一切功能的地基
- **画面**：交互模拟器——上方聊天记录逐条累加，下方固定宽度的「窗口」槽位；拉动滑块（或自动播放）看对话越聊越长 → 塞满窗口 → 最早的记忆被硬生生挤出窗外（淡出+移出）
- **动效**：挤出时浮现一行小字：「它『忘了』——因为那些字已经不在这一趟请求里了」
- **讲者备注**：
  - 点透：忘事不是出了故障，是物理限制——每发一句话，都得把全部旧账重新塞进去一遍
  - 窗口 = 模型一眼能「看见」的字数上限
  - 敲黑板：往后的世界书、总结、向量检索，全是在这扇窗上打补丁
  - **串场**：「大脑天生忘性大，就得配个懂它的掌柜——酒馆这就开张。」

## 第二幕 · ST 是什么

### ⑤ 身世与定位 · 为「折腾党」而生  `~2.5min`

- **目标**：亮出 ST 的名片与家底
- **画面** `[F]`：① 定位（官方原话）：「LLM Frontend for Power Users」；② 时间线：TavernAI 分家（2023）→ 社区接管 → **v1.19.0（2026.09）**，AGPL-3.0，至今仍在高频更新；③ 三标签：开源免费 / 高度可定制 / 社区生态庞大；④ 中文圈昵称：「酒馆」
- **动效**：时间线横向生长
- **讲者备注**：
  - 「Silly」（傻乎乎）是自嘲——骨子里是给「折腾党」打磨的瑞士军刀
  - 中文圈和 B 站都叫它「酒馆」，今晚咱们也这么叫
  - 分家三年多还在高频更新，靠的全是社区一口活气
  - **串场**：「一家小酒馆，凭什么能接下天下所有大脑？秘密在它的骨架里。」

### ⑥ 架构 · 前端与后端分离  `~3min`

- **目标**：立住「界面 ≠ 智能」的核心图式（全场最关键的一页）
- **画面**：左右架构图。左：你手机或电脑上的酒馆吧台（前端界面）；右：后厨任意一颗「大脑」（DeepSeek / GLM / 本地模型 / 免费 Horde）；中间一条线：API 请求（整包上下文）→ / ← 回复流
- **动效**：请求包从左向右飞出、回复流逐字淌回；`[LIVE]` 当场真发一次（LIVE 时架构图与真实请求同步点亮——前后端分离的活证据）
- **讲者备注**：
  - ChatGPT 卖的是捆绑套餐：界面和大脑焊死在一块
  - 酒馆把吧台界面单独拆了出来——后厨大脑随你换，改一行接口地址就接上
  - 刚才的 LIVE 演示和散场后的体验站，靠的全是这招
  - **串场**：「吧台和后厨拆开了，那『大脑货架』上都摆着什么货？」

### ⑦ 万能插头 · 能接的模型谱系  `~2.5min`

- **画面** `[F]`：三行清单，每行一个色块——
  - 云端 API：DeepSeek / GLM / Qwen / Claude / Gemini / OpenRouter……成色最好，按量计费
  - 本地模型：KoboldCpp / llama.cpp / Ollama，普通笔记本就能跑起小模型
  - 完全免费：AI Horde 众包算力、Pollinations——开箱即连，零成本玩遍全套功能
- **要点**：换大脑 = 改一行接口地址，吧台界面、角色卡、聊天记录纹丝不动
- **讲者备注**：
  - 先给大伙儿省钱：免费档就能把酒馆全套功能玩个遍
  - 想追求成色：DeepSeek Flash 档聊上一轮还不到一分钱
  - 本地模型断了网照样转，窝在宿舍就能跑
  - **串场**：「大脑借了别人的服务器，那咱们的家底——存档和数据归谁？」

### ⑧ 你的数据在你手里  `~2min`

- **画面**：对比图——左「网页套壳服务：聊天记录攥在别人服务器里」；右「酒馆：跑在你自己电脑上，聊天记录、角色卡、设定全是本地文件」
- **要点**：跨平台通吃（Win/Mac/Linux，手机浏览器连局域网就能玩）；文件即资产（能备份、能分享、能搬家）
- **讲者备注**：
  - 存档不绑架人：换台电脑，打个包随时带走
  - 这也是我们挑它当社团底座的原因——家底干净、全在本地
  - **串场**：「好话说了半天，该掏句大实话了。」

### ⑨ 诚实的定位 · 它适合谁  `~2min`

- **画面**：左右两栏对照。适合：想把控全局细节的人 / 想摸透 LLM 底细的人 / 创作者·跑团党·陪练党；不适合：只想开箱即用随便聊聊的人（顺嘴带过 RisuAI 等轻量替代）
- **讲者备注**：
  - 把丑话说在前头反而招人信：它确实有安装门槛，也有学习曲线
  - 「至于酒馆这道门槛，正是咱们今晚要亲手拆掉的东西。」
  - 若只想开箱即用随便聊个天，RisuAI 之类更轻的软件更省心
  - **串场**：「吧台搭好了，今晚端什么菜？翻开第三幕。」

## 第三幕 · 能做什么

### ⑩ 角色卡 · 一张 PNG 的魔法  `[HOTSPOT→卡结构深挖]`  `~3min`

- **目标**：端出第一道硬菜：结构化提示词
- **画面**：左边一张角色卡 PNG（教学演示卡，imagegen #4），右边「剥壳」动画分层：名字/描述/性格/场景/示例对话/首条消息——每层点明「全是一格格提示词字段」
- **动效**：`[F]` 逐层剥开；LIVE 模式下右侧字段直接亮出真实 V2 卡的 JSON 摘要
- **讲者备注**：
  - 角色扮演的秘密，说穿了就是一张填好模板的表格
  - PNG 图片只是外皮，藏在里头的结构化 JSON 才是魂
  - 社区百万张现成卡规格统一（V2/V3 规范互通），拖进门就能直接开聊
  - **串场**：「一个角色是独角戏；要是一桌子角色凑一块儿呢？」

### ⑪ 群聊 · 让角色同台  `~2min`

- **画面**：群聊界面示意：一桌角色头像同台，AI 分饰多角轮流接茬，你 @ 谁谁开口
- **要点**：多角色编排 / 发言顺序可调 / 全自动接戏模式
- **讲者备注**：
  - 一颗大脑，独自撑起一台群戏
  - 底子一点没变——还是文字接龙，无非在提示词里塞了句「你现在扮演屋里所有人」
  - **串场**：「人一多、设定一厚，窗口又塞不下了怎么办？下一页，是酒馆最精明的设计。」

### ⑫ 世界书 · 会自己出现的设定  `[HOTSPOT→触发机制深挖]`  `~3min`

- **目标**：悄悄埋下 RAG 的种子，暂不亮出学术名词
- **画面**：设定库列表（蟹堡王、比奇堡、章鱼哥……），下方聊天正热——用户敲出「蟹堡王」，对应那条设定瞬间点亮，「飞入」上方的请求包
- **动效**：关键词命中 → 条目惊醒注入动画；未命中条目继续灰暗沉睡
- **讲者备注**：
  - 几十万字设定塞不进窗口怎么办？酒馆的招数很妙：平时只管睡大觉，聊到哪条才叫醒哪条
  - 「记牢这个动作，第四幕给它揭晓学名。」
  - **串场**：「光会管设定还不算本事，酒馆后头的插件货架才叫眼花缭乱。」

### ⑬ 扩展生态 · 给酒馆装插件  `~2.5min`

- **画面** `[F]`：插件货架逐格亮起——TTS 语音 / AI 绘图 / 自动翻译 / 聊天总结记忆 / 正则（把文字渲染成状态栏、属性面板）/ 用户脚本
- **讲者备注**：
  - 别光看花样多，所有插件干的都是同一件事：改写「发出去的字」，梳妆「收回来的字」
  - 兜兜转转又回到那句老话：一切皆是文字的加工
  - **串场**：「顺着这股改造劲儿，连酒馆的门面都能整张换掉。」

### ⑭ 界面 · 从极客到手机 App  `~2min`

- **画面**：三张真实截图横排（本机 ST 实拍）：桌面深色极客风 / 手机竖屏（活脱脱像聊天 App）/ 自定义状态栏皮肤
- **要点**：主题随便换；手机浏览器直连即用；正则+CSS 能把对话直接画成游戏 UI
- **讲者备注**：
  - 快速带过即可，留到体验站或装好后大家自己上手摸
  - 界面只是前端——外皮随你折腾，后厨大脑纹丝不动（回扣第⑥页）
  - **串场**：「光看菜谱不过瘾，直接端三盘真家伙上桌。」

### ⑮ 玩法案例 · 实录三连  `~4min`

- **画面**：三段实录回放（选项卡切换，各 ~40s）：① 跑团 GM：掷骰判定+状态栏+推着剧情走；② 语言陪练：边聊边纠错+随时入戏；③ 小说共创：你起个头、AI 顺着接龙改写
