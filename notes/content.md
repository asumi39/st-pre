## ① 封面 · 今晚，酒馆开张

- **目标**：10 秒内建立氛围与好奇
- **画面**：大标题「今晚，酒馆开张」，副题「SillyTavern：一个通往无数世界的前端」；署名 AI 社团 + 日期；背景为封面主视觉插画（暗色酒馆一点烛光）
- **动效**：标题逐字浮现（SplitText，烛光摇曳的光影微动）
- **备注**：开场白——"今晚不讲 PPT，讲一个能玩的东西。你们中间有人听过'酒馆'这个词吗？"

## ② Hook · 先看一场对话

- **目标**：让观众"看见效果"，再抛出核心问题
- **画面**：居中一个聊天窗口组件，播放一段真实感角色对话回放（流式逐字，含角色表情文字/动作描写），3~4 轮即止
- **动效**：`[LIVE]` 对话逐字流式（模拟罐头；LIVE 开关可切 DeepSeek 实时生成同一角色）
- **备注**：放完提问——"刚才这段对话，是谁在'扮演'？它真的记得自己是谁吗？它读过角色设定吗？"停顿。"答案可能和你想的不一样。"

## ③ LLM 是什么 · 一个文字接龙机器

- **目标**：30 秒建立"逐 token 生成"的正确直觉
- **画面** `[F]`：① 一句话定义："大语言模型只做一件事：预测下一个字"；② 演示条：输入"海绵宝宝去蟹堡王上"，逐字接出"班，路上遇到了派大星……"；③ 关键句："所谓'人设'，本质上只是喂给它的文字"
- **动效**：`[LIVE]` 接龙逐字动画（SplitText；模拟=罐头节奏，LIVE=真调 DeepSeek）
- **备注**：用"文字接龙"类比贯穿全场；强调没有神秘的"灵魂"，只有概率。"你看到的每个字，都是它一个一个猜出来的。"

## ④ 它没有记忆 · 上下文窗口

- **目标**：理解"每轮都重发全部历史"，这是理解 ST 一切功能的地基
- **画面**：交互模拟器——上方聊天记录逐条累积，下方一个固定宽度的"窗口"槽位；拖动滑块（或自动播放）看消息变多 → 窗口塞满 → 最早的消息被挤出（淡出+移出动画）
- **动效**：挤出时配一行小字："它'忘了'——因为那些字已经不在这次请求里了"
- **备注**："所谓失忆不是故障，是物理限制。记住这页，后面世界书、总结、向量检索全部都是在这件事上打补丁。"

## ⑤ SillyTavern 是什么 · 为"折腾党"而生

- **目标**：给出 ST 的身份卡
- **画面** `[F]`：① 一句定位（官方原话）："LLM Frontend for Power Users"；② 时间线小条：TavernAI 分叉（2023）→ 社区接管 → v1.18（2026.05，仍在活跃更新）；③ 三个标签：开源免费 / 高度可定制 / 社区生态庞大；④ 中文圈昵称："酒馆"
- **动效**：时间线横向生长
- **备注**："'Silly'（傻乎乎）这名字是自嘲——它确实是给爱折腾的人准备的瑞士军刀。B 站上叫它'酒馆'，今晚我们也这么叫。"

## ⑥ 架构 · 前端与后端分离

- **目标**：建立"界面 ≠ 智能分离"的核心图式
- **画面**：左右架构图。左：你手机/电脑上的酒馆界面（前端）；右：任意一个"大脑"（DeepSeek / GLM / 本地模型 / 免费 Horde）；中间一条线：API 请求（你的全部上下文）→ / ← 回复流
- **动效**：请求包从左到右飞行、回复流逐点返回；`[LIVE]` 现场真的发一次（LIVE 开关时此图与真实请求同步点亮）
- **备注**："ChatGPT 是捆绑套餐：界面和大脑焊死。酒馆把界面拆出来单卖——大脑随你换。今天的 LIVE 演示和待会儿的体验站，用的都是这条原理。"（体验站若未上线则改为指南站话术）

## ⑦ 万能插头 · 能接的模型谱系

- **画面** `[F]`：三行清单，每行一个色块——云端 API（DeepSeek / GLM / Qwen / Claude / Gemini / OpenRouter…）· 本地模型（KoboldCpp / llama.cpp，笔记本就能跑小模型）· 完全免费（AI Horde 众包算力、Cloudflare Workers AI）
- **要点**：换模型 = 改一个接口地址，界面、角色卡、聊天记录全部不动
- **备注**："对同学们最实际的：免费档就能玩全部功能；想要质量，DeepSeek 一次对话不到一分钱。"

## ⑧ 你的数据在你手里

- **画面**：对比图——左"网页服务：聊天记录在别人服务器"；右"酒馆：跑在你自己机器上，聊天记录/角色卡/设定全是本地文件"
