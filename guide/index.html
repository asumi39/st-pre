第一步 · 装酒馆三条上手路径，任选一条

装的是同一个软件。三条路殊途同归：装完都会在浏览器打开 http://localhost:8000。推荐从「最快」开始，玩起来之后再考虑换路。

最快 · 10 分钟

一键整合包

下载 → 解压 → 双击。零命令行，适合先玩起来。

  1. 打开 SillyTavern 官方 GitHub Releases，在最新版本的 Assets 里下载 ZIP 压缩包。
  2. 解压到任意文件夹。
  3. 双击 Start.bat（Windows）；macOS / Linux 在终端运行 Start.sh。
  4. 浏览器打开 http://localhost:8000，酒馆开张。
正统 · 5 分钟

git clone + Node（社区推荐姿势）

先装 Node.js（18 或更新版本），然后一条命令：

git clone https://github.com/SillyTavern/SillyTavern.git && cd SillyTavern && npm install && node server.js

浏览器打开 http://localhost:8000。好处：以后更新只要 git pull 一行命令。

极客 · Docker

自托管（我们体验站的跑法）

装好 Docker 后，官方镜像一条命令常驻——社团体验站就是这么部署的，多人共用一个酒馆。

docker pull ghcr.io/sillytavern/sillytavern:latest
docker run -p 8000:8000 ghcr.io/sillytavern/sillytavern:latest

浏览器打开 http://localhost:8000。想长期玩、数据留在容器外，按官方 Docker 文档挂载数据目录。

装好 ≠ 玩起来

装好只是有了「酒馆」这个界面，它还不会说话——下一步给它接一个大脑（模型）。

第二步 · 接大脑模型接入：三件套

酒馆自己不带模型，说话的「大脑」由你接进来。最通用的接法是 OpenAI 兼容自定义端点——填三件套即可。推荐 DeepSeek：注册即得，Flash 档一次对话不到一分钱。

DeepSeek 三件套（推荐）

先去 DeepSeek 开放平台注册，创建一个 API Key。

API 地址
https://api.deepseek.com/v1
API Key
sk-xxxx 用你自己注册生成的那串（也是 sk- 开头）。Key = 钱包，别外传，见下方三条纪律。
模型名
deepseek-flash

在酒馆里的位置：左上角插头图标（API 连接）→ API 类型选 Chat Completion → 来源选 Custom (OpenAI-compatible) → 依次填 API 地址和 Key → 点连接，模型列表里选 deepseek-flash。

模型名避坑

SillyTavern 官方文档的 DeepSeek 条目里写的还是 deepseek-chat / deepseek-reasoner，已过时。以 DeepSeek 官方文档（api-docs.deepseek.com）为准：现行填 deepseek-flash。

不想花钱？两条免费路

① 内置免费档——AI Horde / Pollinations：酒馆开箱即用，无需注册 Key，代价是共享算力要排队、速度看运气。第一次打开酒馆时按引导选「免费」就能试。

② 本地 Ollama——去 ollama.com 装好后，ollama pull 模型名 拉一个本地模型，酒馆里 API 来源选 Ollama、地址保持 http://localhost:11434 即可。断网也能玩，隐私最强，代价是吃你笔记本的性能。

纪律 · 安全与避坑Key 安全：三条纪律

不是免责套话，是真实世界的使用纪律——和幻灯片第 20 页一致。

纪律 01 · KEY

API Key = 钱包

别提交到 GitHub，别发群里，别贴截图。泄漏 = 别人拿你的钱包刷 API。本页教程里的 sk-xxxx 只是占位符，真 Key 只能是你自己注册的那串。

纪律 02 · 隐私

云端 API 看得到你的全部对话

发出去的每个字都会经过别人服务器——隐私内容想清楚再发。想要隐私最强档，用本地模型（Ollama）。

纪律 03 · 分寸

内容有护栏，底线要自己守

违法有害内容别碰。社团体验站有日志——互联网没有真正 deleted。

自托管要清楚

SillyTavern 官方明示：多用户密码是「非安全特性」，全部数据明文存储。它只是门禁，不是保险箱——多人共用一台酒馆时，别把敏感内容放上去。

加菜 · 角色卡角色卡：拿来即玩

不会写提示词没关系——角色卡里藏的就是现成提示词（名字、人设、开场白的结构化设定），导入即玩。V2 / V3 规范的 PNG 卡直接拖进酒馆窗口就完成导入，JSON 卡在角色管理里点导入。

最干净的起点：官方自带示例卡

SillyTavern 仓库自带几张示例角色卡，随软件一起分发，版权干净（开放源码许可）：

  1. 打开官方仓库 default/content/ 目录（Seraphina、Eldoria 等都在这里）。
  2. 点开 default_Seraphina.png，右上角「下载原始文件」保存 PNG；或直接用这张直链。
  3. 把 PNG 文件直接拖进酒馆窗口（角色面板）——完成导入，开聊。

玩多了自然会看懂卡里的门道：从改一张现成的卡开始，比从零写快得多。

深挖 · Q&AFAQ：最常被问的四件事

手机能玩吗？

能。电脑上跑酒馆，手机浏览器访问同一个局域网地址即可——界面本来就是竖屏聊天 App 的样子。也有 Termux 全手机方案，属于进阶折腾；社团分享现场，扫码用我们的体验站最省事。

要花钱吗？

软件本身永久免费开源。大脑：AI Horde / Pollinations 免费开箱即用；想要质量，DeepSeek Flash 档一次对话不到一分钱；本地模型 = 电费。

和 Character.AI 什么区别？

C.AI 是捆绑套餐：模型、界面、数据都在别人服务器。酒馆只拆出「界面」这一层——大脑随便换、数据在你手里、提示词全透明可改。

不会写提示词怎么办？

从现成角色卡开始（见上一节），导入即玩。玩多了自然会看懂卡里的门道——从改一张卡开始，比从零写快得多。
