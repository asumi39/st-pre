第一步 · 装酒馆三条上手路径，挑一条走

三条路装的是同一间酒馆，殊途同归——装好都在浏览器打开 http://localhost:8000。新手直接走「最快」那条，先玩上手，以后随时能换。

最快 · 10 分钟

一键整合包

下载 → 解压 → 双击。全程零命令行，落地就能跑。

  1. 打开 SillyTavern 官方 GitHub Releases，展开最新版的 Assets，下载里面的 ZIP 压缩包。
  2. 解压到顺手的文件夹。
  3. 直接双击 Start.bat（Windows）；macOS / Linux 打开终端跑 Start.sh。
  4. 浏览器打开 http://localhost:8000，你的酒馆正式开张。
正统 · 5 分钟

git clone + Node（社区推荐姿势）

先装好 Node.js（18 或更高版本），再跑这一条命令：

git clone https://github.com/SillyTavern/SillyTavern.git && cd SillyTavern && npm install && node server.js

浏览器打开 http://localhost:8000。甜头在后头：日后升级只要 git pull 一行命令。

极客 · Docker

自托管（我们体验站的跑法）

装好 Docker，官方镜像一条命令后台常驻——今晚的社团体验站就是这么跑的，一间酒馆多人同坐。

docker pull ghcr.io/sillytavern/sillytavern:latest
docker run -p 8000:8000 ghcr.io/sillytavern/sillytavern:latest

浏览器打开 http://localhost:8000。打算长住、想把存档留在容器外，照着官方 Docker 文档把数据目录挂出来。

装好 ≠ 玩起来

装好这步，只是搭起了「酒馆」的吧台，它还不会开口——下一步，给它接一颗大脑（模型）。

第二步 · 接大脑模型接入：三件套

酒馆本身不带模型，负责接话的「大脑」由你任选接入。最通用的接法是 OpenAI 兼容自定义端点——填齐三件套就行。首推 DeepSeek：注册即用，Flash 档聊一轮不到一分钱。

DeepSeek 三件套（推荐）

先去 DeepSeek 开放平台注册账号，新建一把 API Key。

API 地址
https://api.deepseek.com/v1
API Key
sk-xxxx 用你自己注册生成的那串（也是 sk- 开头）。Key = 钱包，别外传，见下方三条纪律。
模型名
deepseek-flash

进酒馆照着点：点左上角插头图标（API 连接）→ API 类型选 Chat Completion → 来源选 Custom (OpenAI-compatible) → 填入上方的 API 地址和 Key → 点连接，模型列表选 deepseek-flash。

模型名避坑

SillyTavern 官方文档的 DeepSeek 词条里还印着 deepseek-chat / deepseek-reasoner，已经过时。请以 DeepSeek 官方文档（api-docs.deepseek.com）为准，现在一律填 deepseek-flash。

不想花钱？两条免费路

① 内置免费档——AI Horde / Pollinations：开箱即用，不用注册 Key；代价是蹭公共算力得排队，快慢看运气。首次进酒馆按引导选「免费」就能直接试。

② 本地 Ollama——去 ollama.com 装好软件，终端跑 ollama pull 模型名 拉一颗模型到本地；回酒馆把 API 来源设为 Ollama，地址留默认的 http://localhost:11434 就成。断网照样聊，隐私最稳，代价是烧你笔记本的显卡和内存。

纪律 · 安全与避坑Key 安全：三条铁律

这三条不是免责套话，是真金白银换来的铁律——和幻灯片第 20 页一致。

纪律 01 · KEY

API Key = 钱包

别传上 GitHub，别发群里，别截进图里。Key 一旦漏出去，等于把钱包递给别人刷。本页写的 sk-xxxx 只是占位符，真 Key 必须去平台自己领。

纪律 02 · 隐私

云端 API 看得到你的全部对话

你发出的每个字都会过一遍云端服务器——涉及个人隐私，落笔前先掂量。真想把话锁死在屋里，跑本地模型（Ollama）。

纪律 03 · 分寸

内容有护栏，底线要自己守

违法有害内容别碰。社团体验站后台留有日志——互联网上没有真正的 deleted。

自托管要清楚

SillyTavern 官方把话挑得很明：多用户密码属于「非安全特性」，后台数据一律明文存储。那道密码只是虚掩的店门，不是保险柜——多人拼桌共用酒馆时，敏感话别往上放。

加菜 · 角色卡角色卡：拿来即玩

不会写提示词？完全不耽误——角色卡肚子里装的就是写好的全套设定（名字、人设、开场白一应俱全），导入即玩。V2 / V3 规范的 PNG 卡，抓过来往酒馆窗口里一拖就进去了；JSON 卡在角色管理面板里点导入。

最干净的起点：官方自带示例卡

SillyTavern 官方仓库自带几张示例角色卡，随安装包一起发，版权干净（开源许可，放心拿来试手）：

  1. 打开官方仓库 default/content/ 目录（Seraphina、Eldoria 等看板角色都在里头）。
  2. 点开 default_Seraphina.png，点右上角「下载原始文件」存好 PNG；嫌麻烦直接点这张直链。
  3. 把存好的 PNG 图直接拖进酒馆窗口（角色面板）——人就落座了，开聊。

聊上几轮，卡里的门道自然就摸清了：先从改一张现成的卡下手，比对着白纸硬憋快得多。

深挖 · Q&AFAQ：最常被问的四件事

手机能玩吗？

能。电脑后台挂着酒馆，手机连同一局域网，用浏览器敲地址就能进——酒馆做出来本来就是竖屏聊天软件的模样。硬核玩家还能用 Termux 把整套塞进安卓机；今晚在分享现场，直接扫码进社团体验站最省事。

要花钱吗？

酒馆软件本身永久免费开源。至于接进来的「大脑」：AI Horde / Pollinations 免费开箱即用；追求质量，DeepSeek Flash 档聊一轮不到一分钱；跑本地模型只花你家那点电费。

和 Character.AI 什么区别？

C.AI 卖的是捆绑套餐：模型、界面、聊天记录全攥在别人手里。酒馆只做纯粹的「吧台界面」——大脑随你换，存档留本地，底层提示词每一行都摊开任你改。

不会写提示词怎么办？

往上翻一节，先拿现成的角色卡上手，拖进来就能聊。等拆过几张好卡，写法自然就通了——踩着现成模板改，永远比硬憋快。
